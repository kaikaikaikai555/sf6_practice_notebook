# 🥋 SF6 Practice Notebook（スト6対戦反省・キャラ対策ノート）

ストリートファイター6（SF6）の対戦データを素早く記録し、自分の敗因傾向やキャラクター別の対策を効率的に管理・分析するためのWebアプリケーションです。
